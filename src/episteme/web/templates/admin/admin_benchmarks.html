quick

A synthetic prompt, seconds not minutes. It overstates prefill by 3-4x against real traffic, so it answers "is the server up and roughly as fast as yesterday" and nothing else.

ladder

One cold prefill per rung, the fixture truncated to each. Generates almost nothing on purpose: this measures how prefill scales with prompt length, and 256 tokens per rung would spend the GPU time on the other half.

sweep (host executor)

Each variant edits models-preset.ini on the host and restarts llama-server. The original file is backed up before the first edit and restored unconditionally at the end, including after a failure. A key set to null is commented out rather than deleted.
