Bootstrap

Two phases on purpose. Propose clusters every free-text topic already in the database and writes a proposal - it changes nothing else. Apply creates the vocabulary rows and rewrites the topic array on every story and post through it. Read the proposal before applying: a bad clustering pass is far easier to reject here than to unpick afterwards.
